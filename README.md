# Rally Stage Tracker

## Быстрый запуск Windows
1. Распакуйте проект.
2. Откройте папку проекта.
3. Дважды запустите `START_RALLY_TRACKER.bat`.
4. Откройте http://127.0.0.1:5000

## Администратор
Логин: `admin`
Пароль: `1987`

## Погода
API-ключ OpenWeatherMap хранится в `.env`. Погода для этапов берётся по координатам и времени этапа из OpenWeatherMap. Кэширование - 5 минут.

## Ручной запуск
```powershell
.\.venv\Scripts\python.exe init_db.py
.\.venv\Scripts\python.exe -m backend.app
```

## Регистрация и управление аккаунтами
- Регистрация отправляет данные в `/api/auth/register`; пароль сохраняется только в виде bcrypt-хеша.
- После регистрации пользователь не входит автоматически: его перенаправляет на страницу входа.
- Администратор может просматривать, блокировать/разблокировать и удалять пользователей, а также редактировать имя, email и роль (user/marshal).
