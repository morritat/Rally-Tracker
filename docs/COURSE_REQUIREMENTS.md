# Rally Stage Tracker — соответствие курсовой

## Этап 2. ТЗ
- Регистрация и авторизация.
- Роли: user, marshal, admin.
- CRUD этапов через API (создание/чтение/изменение/удаление).
- Результаты, телеметрия, радио и видео для этапов.
- Автоматическое получение погоды OpenWeatherMap.
- Адаптивный интерфейс.

## Этап 3. Архитектура
- Клиент: HTML5 + CSS3 + JavaScript.
- Сервер: Python + Flask.
- БД: SQLite.
- API: REST/JSON.
- Авторизация: JWT.
- Пароли: bcrypt.

## Этап 4. UI
Ключевые экраны: главная, этап, вход, регистрация, админ-панель.
Фоновое изображение: `static/img/wallpaper_index.jpg`.

## Этап 5. Реализация
- `backend/routes/` — REST-маршруты.
- `backend/models/` — модели.
- `backend/services/weather_service.py` — интеграция OpenWeatherMap.
- `database/schema.sql` — схема.
- `database/seed.sql` — тестовые данные.

## Этап 6. Тестирование
- Проверка регистрации/входа.
- Проверка ролей и JWT.
- Проверка CRUD этапов.
- Проверка API этапов и погоды.
- Проверка адаптивных экранов.
